# Superseded release artifacts — DO NOT DEPLOY

Every zip in this folder is an old build kept for history only. In particular,
`dist-v2.0-PRODUCTION.zip` predates the v1.9-RC2 citation-architecture work despite
its name — deploying it would ship retracted trust claims.

**The only deployable artifact is the single `dist-vX.Y-RCn.zip` at `website/`
root**, which always matches the latest CHANGELOG entry.
